# Science Fair Projects

| Project | Research question | Language |
|---|---|---|
| [Minesweeper](Minesweeper/README.md) | How do training settings affect an AI's win rate? | Python |
| [Password Security](PasswordSecurity/README.md) | How do length and guessing strategy affect password search effort? | C# / .NET 10 |

The [progress dashboard](Dashboard/README.md) is a plain HTML/CSS/JavaScript
website with a small Python JSON API. It displays completed tests, remaining
tests, percentages, update times, and whether each experiment is still active.
A temporary public tunnel can share the live dashboard without requiring sign-in.

Each folder contains setup instructions and source code. Both projects follow
Science Buddies project ideas; original sources are credited in their READMEs.
Local adaptations were made for these experiments. Results are actual measurements.

Never programmed before? Start with the [beginner guide](BEGINNER-GUIDE.md). The
launchers support Windows, macOS, and Linux on Intel/AMD or ARM computers when
the required Python/.NET runtime is available.

Minesweeper passed 60,000 training games and continues toward 300,000. Password
challenges 0-5 are solved; challenge 6 remains unsolved at publication. Both
local resumable experiments continue independently of this repository snapshot.

Virtual environments, model checkpoints, build output, and process logs are not
included. Third-party files retain their original credits; no blanket license
is assigned to third-party material in this collection.
