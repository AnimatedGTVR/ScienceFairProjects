# Final Minesweeper Results

Start with `Minesweeper-Final.xlsx`. It opens in Excel and can be imported into
Google Sheets. The workbook contains the overview, final trained-versus-random
comparison, training progress, all 4,000 evaluation games, a Science Buddies
checklist, expanded research notes, and the model configuration.

`Minesweeper-Science-Fair-Package.zip` contains the workbook, report, display
board notes, graphs, raw data, and final trained model in one download.

The headline result is 901 wins in 2,000 games for the trained DQN (45.05%) and
260 wins in 2,000 games for random play (13.0%).
